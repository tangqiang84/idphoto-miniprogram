## 四、下午 · 开发 #37 A1 半透明人脸引导框（已完成）

**关键发现（与上午核对结论衔接）**：上午核对认为"相机入口已支持（chooseImage 含 camera）"，但
原生 `chooseImage` 打开的是微信系统相机，**无法叠加引导框 overlay**。要实现 PRD A1「半透明人脸引导框」，
必须改用 `<camera>` 原生组件拿实时预览，再用 `cover-view` 覆盖层画引导框（普通 View 会被压在相机下方）。

**做法**：
1. 新建 `src/components/CameraGuide/index.tsx` + `index.scss`：`<camera>` 实时预览 + `cover-view` 头肩轮廓
   半透明描边 + 正脸/平视/光线提示 + 前后置/闪光切换；`visible=false` 时整体卸载。
2. 新建 `src/hooks/useImagePicker.tsx`：统一两入口——`pickAlbum`（相册，仅 album，保留 `chooseImage`
   以便自动化冒烟 mock）+ `openCamera`（拍摄入口）；`onImage` 回调把 path+尺寸交给各工具真实处理函数。
3. 5 个工具页（T1/T2/T3/T4/T5）改造：把 `process()` 内联取图剥离为 `run(path,w,h)`；`.btn-primary`
   改为走 `pickAlbum`（相册），新增 `.btn-camera` 走 `openCamera`，根 View 渲染 `{picker.Guide}`。
4. `app.scss` 补 `.btn-camera` 次级按钮样式。

**验证（沙箱可跑闸门）**：
- `NODE_OPTIONS= bash 工具链/verify.sh --no-build` → ✅ tsc 0 错误（基线 0 告警）+ core 单测 142/142。
- 新增 `工具链/smoke_camera.js`：UI 结构回归（5 页均有 .btn-camera）+ 引导框挂载/卸载；**真机拍照取图
  依赖真机摄像头，列入 #14 真机冒烟**（模拟器无摄像头，与头占比/600dpi 同口径）。

**设计取舍**：引导框用 `cover-view` + CSS 形状（非 SVG，因 cover-view 不支持 SVG），纯视觉引导、
不依赖人脸检测——与 PRD A1「提示」要求一致，避免自动识别误判伤体验。
