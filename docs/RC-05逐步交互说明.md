## 步骤与动作

| 当前步骤 | 明确动作及后续 | 禁止动作 |
| --- | --- | --- |
| 选图 | 选择规格和已授权照片，进入裁剪；可提供本地裁剪建议 | 不抠图、不生成成品 |
| 裁剪 | 调整原图坐标窗，确认后仅进入美颜 | 确认前segment调用为零 |
| 美颜 | 确认设置或跳过；跳过将enabled设为false，随后才生成处理预览 | 不直接进入结果屏 |
| 抠图换底预览 | 显示实际图片、处理来源、底色和修补；下一步进入可选换装 | 预览不能用于保存或冲印 |
| 换装 | 独立同意后应用模板并核对当前结果五官，或跳过进入预审 | 未自检不能接受已换装结果；拒绝换装不伪装成功 |
| 预审 | 展示当前图片尺寸、大小、底色等报告，通过必需项后进入档位 | 旧参数的预审不能放行新参数 |
| 输出档位 | 300/600档选择、人工镜像自查、确认生成最终成品 | 未预审/未镜像确认不生成最终成品 |
| 成品 | 实际文件尺寸、KB、格式；保存或去冲印排版 | 旧结果/撤销自检/不合格必需项不得被消费 |

每次只渲染当前步骤的内容；换装自检是覆盖当前步骤的对话框。结果预览与最终成品分别标识isFinal。换装最终成品重新生成后再次自检，不能沿用预览的自检。

## 参数与失效

参数继续由RC-04的processingSession持有。t1Workflow只管理步骤和美颜确认、预审、镜像、最终结果的有效凭据；useT1Workflow管理订阅与卸载；t1Processing复用既有图像处理，平台异步都经task.call/check。未新增生产依赖。

- 返回保留原图、裁剪、美颜、底色、模板及档位；修改原图/规格/裁剪必须重新确认裁剪和美颜。
- 修改美颜使处理预览及后续凭据失效；底色、模板、授权变化使相关结果和预审失效。单改dpi保留已完成的同参数预审，重新生成最终文件。
- 镜像凭据绑定原图/裁剪/美颜，改这些输入后必须重查。当前结果绑定revision、traceId和实际路径；同参数重试也不能使用旧保存/修补回调。
- 取消使在途任务失效；不能撤回已发出网络请求。重复点击、迟到回调、失败后重试由会话和步骤守卫控制。

## 兼容与实现边界

CropStep的confirmationRequired、BeautyStep的standalone及DpiStep的有效裁剪像素参数均为可选项，T1启用；其他页面保持既有模式。T1裁剪采用绝对缩放，重复80%不累乘；原生movable-view的change事件将用户移动写回原图坐标，忽略程序定位事件。组件回归覆盖这些断言。

实际基础库3.17.6已无chooseImage，新增相册适配优先chooseMedia，并保留旧API回退、取消和结构化错误。共享选图节点经适配层两条测试及T1/T2/T3/T5页面控制探针回归；其他工具完整流程及真机仍归RC-07/12。

处理缓存保留工作像素、alpha及裁剪映射，换底/dpi重合成保留已确认裁剪，修补点从预览坐标映射到工作坐标。600档工作画布不会增加原图有效像素；高清提示使用原始裁剪窗。最终文件重新测量尺寸和大小；dpi文案仅承诺输出像素档位，不承诺JPEG元数据。

保留现有授权入口，RC-06负责拆分本地与上云授权；模型、换装质量、完整规格与文件质量、错误及生命周期、全工具与真机分别归RC-08至RC-12。本轮不据此宣称这些需求完成。
