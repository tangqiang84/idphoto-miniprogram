# RC-08 像素与最终导出一致性

依据为PRD H1/H2/H2.1/H2.2、F2、AC4、K模块，九规格/相纸使用仓库已确认参考表，未重新裁决外部机构要求。开工与历史留痕见[开工检查](RC-08开工检查.md)，本轮证据在`验证记录/RC-08-implementation`。

## 像素档位与清晰度

300/600dpi是根据物理规格换算目标像素的产品档位，不承诺把该值写入JPEG/PNG元数据。相纸档位沿用300或ZINK原生313。平台导出器可能附带其他DPI值，应用未主动写入；页面不把档位当作文件元数据实测值。

每个新成品记录pixelEvidence：source为原图尺寸；effective为原图坐标的确认裁剪窗；work为实际处理画布；processingCrop为处理画布中的导出裁剪区；segmentationInput为分割接口入口尺寸（T5为null）；target为目标输出。segmentationInput不是神经模型内部输入，内部模型缩放/输出质量留RC-09。

DpiStep使用effective判断原图细节，processingCrop另判断处理分辨率。不再用放大后的workW/H替代原图；缺失有效窗明确未知。源窗不足或处理分辨率不足在档位/成品提示，像素充足也不宣称算法质量合格。T5自定义目标固定像素同样显示有效窗评估，不随dpi翻倍。

## 实际文件核验

exportInspection集中读取getImageInfo与文件原始字节，通过outputEvidence校验实际宽高、实际JPEG/PNG类型和正数字节数。请求扩展名/画布尺寸不能替代实测；缺失格式、尺寸不符或无效字节拒绝，不生成可消费成品。JPEG的jpeg/jpg标记归一化，不按扩展名推测。

T1/T2/T3机构KB规则按未经取整的bytes/1024比较；例如204801字节不会因四舍五入成200而通过200KB上限。显示值可保留两位，但不作为判定输入。沿用当前PRD区间硬检查及RC-07已确认其余检查保留，600档机构KB只提示。T5用户显式KB上限不因600档而免除，以最后一次核验字节判定，无法压到上限就拒绝；0为不设自定义压缩上限。按工具重写检查项后同步重算汇总pass和建议。工作流硬失败清空finalResult，不留下失败成品对象。

共享t1Processing覆盖T1/T2/T3/T5；既有renderService也接相同落盘核验。内部读图/文件操作有超时；任务失效由既有会话阻止回写，对外错误沿用安全包装。

## 排版几何与承诺

printGeometry按原相纸/规格SSOT和原margin/gap输出纸张、居中可打印区及每张placement，在毫米坐标计算后一次像素舍入，避免累计整数步长误差。逐项检查张数、区域边界；instax/方形贴纸至多一张，放不下则不导出。

整纸旋转时画布和可打印区一起转。当前bestTiling的并列优先顺序选择整纸旋转，照片旋转组合不可达；绘制保留正确的显式照片旋转实现，但不把该分支认作实际SDK覆盖。尺寸依据参考表的152×102mm，6寸不是重新改用152.4×101.6mm。

T6落盘也核验真实尺寸/格式/字节，结果变化时清理旧预览；保存检查忙状态和镜像自查。开启参考线会写入拼版图，页面文案已纠正。关闭该开关才不绘制参考线。白边不可用于拼版，物理打印比例应在打印软件中按相纸尺寸设置；实体打印机误差不由模拟器文件测试证明。

## 验证边界

九规格双档固定值与16相纸整纸固定值来自确认参考表，独立于产品换算函数。四工具72条页面/适配路径、字节边界、未知/小裁剪与格式反例分别验证；微信使用授权REAL-111固定样本、禁云副本串行执行并保留失败证据，最终文件另用现有Pillow运行时读出。真实模型/模板质量、完整生命周期、双平台实体机及发布全量覆盖仍属后续任务。
