## 处理建议

1. 保留USER08失败样本及原端侧失败；不靠提高alpha硬阈值抹掉绿边，这可能损伤发丝和浅衣。
2. 现有百度适用于本批暗光主体改善，但不能作为复杂背景质量达标依据；不自动升级为默认生产模型。
3. 后续需要独立的发丝/背景标注与边缘颜色评估，区分错分和RGB污染后再选修复路径；云端更精细模型/接口若超出现有服务范围须另行决策，不能沿用三次图片调用授权。
4. 端侧模型正式资源准入/生产分发、Android/性能、地域及第三方留存训练条款等仍缺证据。资源门禁3 FAIL/5 BLOCKED/1 SKIPPED保持。
