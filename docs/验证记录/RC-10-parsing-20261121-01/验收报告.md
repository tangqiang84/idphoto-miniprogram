# RC-10 衣物解析修复与验收报告

2026-11-22。状态：**进行中，未全部完成**。本轮实现与云端资源部署已完成；当前证据不足以把 RC-10 全部验收项标为完成。用户要求无需真机，真机项记 N/A，不据此声称设备兼容通过。

## 修改与根因

上一轮仅人体 alpha + 透明模板，无法移除模板外旧高领。新增固定六分类解析，分开处理衣物与背景；衣物移除后再放置模板，背景只收紧下巴保护线以下 alpha。保留原高分辨率像素，不生成或重绘五官。

实测关键点凸包加额头保护 alpha；无关键点时保护整个脸框。原有全脸框 RGB 零差分、下巴线以上全宽 RGB 零差分继续执行，新增保护区 alpha 零差分。模型缺失/异常/撤回/过期则停止，不用估算或经典算法假装衣物识别成功。修补上限采用新衣实际 alpha，避免恢复旧衣。

新增 `core/suitClothing.js`、`services/clothingService.ts`、固定模型元数据及测试；共享 `t1Processing.ts` 接入 T1/T3，`wechatInference.js` 支持固定 NHWC/六分类形状，MODNet 默认形状不变。`faceService.ts` 透传现有实际关键点。云端仅增加公开模型资产路由，不在云端解析新照片。模板与模型持久缓存按摘要复用；损坏缓存保留另写，不删除已有数据。UI 提示首次下载约16MB。

没有新增生产依赖或修改锁文件、密钥、原有 dist；没有追加照片上传、百度推理、重试或付费启用。

## 失败与未执行项

局部颜色细化首个合成测试把同一蓝色同时当成高置信衣物和皮肤，预期误写为必须移除；已更正为可区分种子，并补相同距离时保持皮肤的反例。半透明测试最初用源alpha=0.5，触发既有严格大于0.5门禁；有效样本改0.75，仍断言固定0.75×128/255，未放宽接受阈值。失败日志均保留，最后重新运行全部检查。

不继续靠移动肩线、修改脸部保护阈值或删除失败图获取通过。剩余：可靠脸点+真实姿态+微信解析模型完整链成功记录；历史盖脸实图同链重测；跨素材领口/双肩自然度与边界质量。当前模型在局部不确定身体/衣物边界仍有误分类，应以独立失败集合比较解析能力，不能靠此一张NASA调阈值。未清理用户文件、未再请求照片上云授权、未提交审核或发布。
