# RC-10 衣物解析根因修复

需求RC-10，影响T1/T3合成与导出alpha。基线：上轮NASA实图三模板原高领残留，根因已证实人体alpha不能区分衣服与皮肤。停止几何调参。

先本地评估Google MediaPipe六分类模型的固定ONNX转换；复用已有onnxruntime，不安装生产依赖、不发送照片。依据：官方类别含背景/头发/身体皮肤/面部皮肤/衣服/其他；低分辨率语义用于移除旧衣，保留原高分辨率人体matte。

计划文件：新的纯逻辑衣物后处理、平台模型适配、T1/T3共享处理、独立反例与本地实际推理工具。仅在本地实际实验支持后接线，不以“接通”代替质量。

断言：不换装路径像素不变；脸/皮肤/头发不被旧衣移除；模板有效区域仍可见；撤回及过期任务不继续；模型不可靠时拒绝而不是继续旧衣残留成品；9规格/双档及T1/T3关联回归。

结构性理由：仅人体alpha+透明贴图无法移除模板外旧高领，需新增语义mask，保持core纯逻辑、平台推理服务与现有链路分层。保留原图/旧报告以便回退，不覆盖dist，不修改密钥，不启用付费或追加云照片调用。
