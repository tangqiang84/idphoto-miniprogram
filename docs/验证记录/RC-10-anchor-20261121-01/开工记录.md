# RC-10 肩线锚定修复

需求 RC-10，影响 T1/T3。前置 RC-07/RC-09 按用户研究/本机范围满足；整体待人工验收。

复现：构造有显式模板肩峰的可靠脸与双肩坐标，经 fitSuitV2 和 suitCompose 的同一中心旋转变换投影模板肩点；现有实现忽略 shoulderY，且限宽/旋转会使锚点离开实测坐标。

修改计划：新增纯逻辑肩峰相似变换；研究模板加入人工图像肩峰标注，保持原PNG；fitSuitV2 在显式锚点存在时使用测量变换，严格核对元数据与领口保护；测试验证0/正负角度、平移缩放、出画裁剪以及退化/冲突拒绝。旧模板分支保持兼容，不升级依赖。

验收断言：两个模板锚点经真实合成中心变换后分别映射到实测肩点；不以缩小模板来塞进画布；坐标冲突明确拒绝；脸部像素仍不变。合成与人工标注不冒充真实模型质量成功。

不涉及外发照片、付费、密钥、dist覆盖、真机或发布。此前三次上传预算耗尽。
