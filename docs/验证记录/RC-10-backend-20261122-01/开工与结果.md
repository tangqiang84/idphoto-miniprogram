# RC-10 后端替代实现

2026-11-22。依据用户授权替换现有方案，新增独立suitparse/index.py，尚未部署或切换前端。影响范围将为T1/T3衣物解析，其他工具不接此接口。结构调整原因是现有微信原生推理在模拟器不可用，换用可独立执行的CPU后端；不迁移整个处理链，脸保护/模板合成仍归现有core。

新增代码已读取旧posekey、cloudFnAdapter及现有本地模型实验。接口验证：6个非法请求在模型创建前拒绝；固定NASA本地请求成功，约4.5秒（含首次模型加载），3个旧残点均判上衣。照片上云0。峰值RSS894296064字节约853MiB，仅代表本机进程，不能推断当前云资源可运行。

新增生产候选依赖说明见suitparse/README.md：numpy/Pillow/onnxruntime CPU，不安装进现有前端，不更改锁文件。尚未准备Linux运行时包，未变更云函数内存或计费配置。云函数默认256MB不足以依据本机实测声称可用，需资源核实后再部署。

来源：https://docs.cloudbase.net/cloud-function/runtime-support 、https://cloud.tencent.com/document/product/583/55594 、https://cloud.tencent.com/document/product/583/73923 。官方支持Python及依赖打包，压缩前函数+层总计限500MB；本轮尚未验证可部署包体。

本轮不是完整RC-10验收：跨样本自然度、自动脸点完整链、实际云调用、撤回授权的客户端接线均仍待验证。新增函数不自动替换旧服务，不把未部署功能标完成。
