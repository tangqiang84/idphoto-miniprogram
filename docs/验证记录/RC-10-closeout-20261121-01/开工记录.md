# RC-10 研究版开发收尾

需求：RC-10，影响 T1/T3 共享换装。用户决定三张素材直接用于研究，并要求完成开发；延续不要求用户真机验收的决定。

基线：研究脚本54项夹具合成通过，但小程序仍只有未批准旧模板；姿态默认调用未部署的 Python posekey，现有已部署 matting 才有百度配置。因此用户无法实际使用新模板。

计划：新增研究模板目录、按需原图传输与摘要核对；共享页面和处理器接入研究模板；复用已配置的 matting 增加姿态路由，避免复制/读取密钥；串行部署与源码回读。原模板保留。

拟修改：suitTemplates、processingSession、PhotoTool、t1Processing、poseService、cloudFnAdapter、matting入口及新增云端模块、相关测试与说明。

验收：模板可选择并加载；原图SHA匹配；跨规格几何一致且不盖脸；T1/T3共享处理和二次自检；无授权零姿态上传；多人/缺肩点/过期结果拒绝；callback/Promise SDK兼容；测试、类型、Lint、隔离构建；代码部署回读。

不涉及：商用权利确认、正式发布、采购、密钥/环境变量变更。模拟结果不冒充真人自然度或真实姿态服务可用证明；相关验收仍按实际证据记录。
