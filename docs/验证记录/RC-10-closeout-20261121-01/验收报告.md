研究版代码开发与云端部署已完成：三张用户模板已接入小程序 T1/T3，默认白色正装，真实模板按需加载；百度双肩分析通过现有 matting 的 pose 路由，复用已有配置，不再依赖另行配置 Python posekey。RC-10 整体状态为“待真机/人工验收”：真机按用户决定不执行，真人视觉质量和真实姿态成功记录尚缺，不能标记整体完成或发布通过。

## 修改内容

- 三张原图保留，云函数内新增同摘要原件与固定白名单清单；小程序只打包160px缩略图。原图512KiB分片按需下载，逐片检查元数据，整体SHA-256核验后保存。当前进程复用缓存；撤回授权或会话失效后停止后续请求并丢弃结果。未声称能撤回已经发出的请求。
- T1/T3共用模板目录、处理器、授权和像素保护；切换模板/规格后旧结果、自检失效。预览和最终结果分别要求自检。页面明确研究用途且保留“仅换装、不改五官”。
- 新增云端百度body_analysis路由：双授权契约、用途/尺寸/请求体限制、单人计数、完整双肩/置信度校验、无自动重试，网络异常记录安全码与TraceID，不回传提供方原始异常。客户端复用callback/Promise桥接，迟到结果再次检查授权。
- 修复高分辨率模板缩放不一致：固定像素倍率改为400px参考画布归一倍率。四倍画布基线失败已保留，修复后同比缩放通过；0.5肩点和15度阈值未放宽。
- 姿态解析不再把超过1的置信度钳成1；保留异常值供可靠性门禁拒绝。原始错误描述不进入用户提示。
- 两张2500px素材不满足大二寸600dpi所需2504px原生长边，继续拒绝该组合；4096px白色模板支持九规格。没有放大或四舍五入门槛。
