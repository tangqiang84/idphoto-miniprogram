# 保留初次数学对照失败

js-validation.json是首次JS验证运行产生的空输出，运行退出码1，终端VALIDATION_FAILED。失败发生在将“每个ORT归一化结果都应通过双精度公式比较”作为断言时，具体数据随后完整写入math-diagnostic.json。

8组中zero-245最大误差0.0034051345010794876，193548个元素超出现有绝对/相对容差；其他7组通过。没有删除该样本、放宽容差或把结果改PASS。

随后用NumPy独立双精度公式核对JS统计，8组最大误差与超差元素数均一致。js-validation-final.json区分“检查器与NumPy一致PASS”和“ORT数学基线7 PASS/1 FAIL”。本轮可以继续使用已交叉验证的检查器诊断实际手机输入，但不得把ORT基线FAIL归责微信或宣称模型全量通过。
