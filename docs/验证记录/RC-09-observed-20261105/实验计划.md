# RC-09 完整图观察实验计划

范围：RC-09模型数值故障，不更改PRD或原型。基线：前5个独立前缀PASS，完整静态/动态图FAIL且各262144个非有限输出。

计划修改：新增完整图观察生成器及隔离页；修正诊断比较器“无有限比较仍显示差0”的显示错误及测试。保留原始模型、生产代码、精度、epsilon及验收阈值。

验收：一个完整动态图新增节点224/298/389/442/482/485的观察输出，同时保留最终输出；CPU零/非恒定输入的最终输出与原图对照；所有派生字节固定SHA并经JS增量重建验证。手机同一包运行观察图/原图×零/非恒定输入，分别记录每个输出NaN/Inf及抽样差异。任何观察图PASS不替代原图验收，观察本身可能改变融合。

存储：仅新增一个约26MB观察模型，四组运行复用同一派生文件/原缓存，禁止继续新增一批前缀文件。只读盘点文件实际大小后执行显式诊断预算检查；不删除、不覆盖既有文件。若缓存或存储条件不足则停止，绝不自动下载。

未执行：手机对照、实际失真层定位、模型修复、照片/Android/性能验收。RC-09保持阻塞。
