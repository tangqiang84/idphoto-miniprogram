# 云失败安全诊断补齐

2026-11-10。共享cloudFnAdapter新增可选onDiagnostic，只返回phase、sdkCode（安全整数）、traceId、elapsedMs；SDK异常包装为安全可读错误，区分SDK_REJECTED/TIMEOUT/FUNCTION_ERROR/RESULT_RETURNED。异常日志为同一白名单，原始errMsg/URL/请求/照片/凭据不透传。观察回调异常被隔离，不影响业务结果；授权前后检查和云失败本地回落保持。

基线：新增两项测试在原版失败，保留baseline.log；修改后130工具/404核心/类型/Lint/隔离构建通过，见tools.log、verify.log及checks/run-20261110-015022-d1379b0f/report.json绑定源码/工作区/构建。测试包含SDK错误码与敏感载荷隔离、观察失败不改变成功、函数额度17保留；真实15秒适配器及撤回测试随工具回归通过。

无真实云请求/新照片上传/部署/费用。旧手机失败没有该诊断数据，不能通过新代码回溯其原始错误，也不能凭CLOUD_UNAVAILABLE猜环境或权限。下一真实请求须另有明确授权，既有手机预算已耗尽。新能力为诊断准备通过，手机云链仍FAIL/未定位。当前生产未默认落盘SDK错误，无日志照片；如需手机可读则在新的受限验收副本用onDiagnostic仅保存白名单。
