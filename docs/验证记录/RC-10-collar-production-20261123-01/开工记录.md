# RC-10 领口拟合生产迁移

范围T1/T3。替代旧肩峰刚性贴合；双肩继续作可靠性闸门，实际服装位置由领口开口与可见皮肤拟合，记录新来源而非伪称两肩完全对齐。
计划：独立suitfit CPU函数仅返回几何，小程序用原高清模板和原像素合成；识别图≤768，保留原裁剪/美颜；新增掩码保护合成器，脸部RGBA与alpha仍逐像素不变，不再把整条下巴水平线上所有非脸区域都当脸。
基线：Pro混合本地原型三模板领口改善且脸差分0，NET04三模板拒绝。新几何必须先用同图当前核心验证，不能仅凭原型画面宣称迁移成功。
验收：协议输入/授权/来源验证、高清坐标转换、领口孔洞与保护区、T1/T3异步撤回、模型内存、类型/Lint/构建/关联回归。新真人云调用须独立确认，不复用已耗额度。不升级套餐。
