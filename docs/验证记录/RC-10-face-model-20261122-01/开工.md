# RC-10 自动人脸候选验证

目标：消除人工脸点验收依赖；不直接替换现有端侧隐私路径。计划固定MediaPipe0.10.21与官方FaceLandmarker float16/1模型，本地CPU验证授权NASA单脸、纯色负例、同照片拼接多人负例。num_faces=2避免把多人输入截断成单人；不生成身份向量或表情输出。模型摘要见model-source.json。

新增依赖仅安装隔离Docker实验目录，不修改生产依赖或锁文件；若未来引入云人脸服务，须独立保留上云授权边界及原端侧路径，不能仅为了模拟器验收改变产品隐私承诺。现阶段仅技术候选，不代表已集成或完成RC-10。照片上传0。

依据：https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker 。验收必须区分模型实测关键点、由关键点包围盒推导的rect及既有头顶比例估算；不能把包围盒与同源点自洽视为独立检测证据。
