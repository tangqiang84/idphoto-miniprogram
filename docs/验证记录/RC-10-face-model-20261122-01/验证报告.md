# RC-10 自动人脸候选验证结果

2026-11-22。整体仍进行中，不能标完成。

官方MediaPipe0.10.21 FaceLandmarker固定float16/1权重，来源及SHA见model-source.json。Linux断网CPU实际检测：NASA、OWNER-01、NET-02、NET-04均检出1脸；纯色图0脸、同照片拼接图2脸。后两者仅合成负例，不计为独立真实样本。

NASA采用真实模型478点替代人工脸点，现有face.analyzeFace计算头部度量，再使用此前录制的百度肩点、真实云解析类别图和生产合成core回放。25规格模板成功，2个模板分辨率预期拒绝；保护区RGB/alpha差分0。白色完整工作画布目视未见此前低分辨率实验的块状脸边缺口。证据automatic-replay及summary.json。

关键限制：这不是小程序生产全链。当前faceService仍使用微信端侧API，本候选未集成、未部署。人脸rect由landmark包围盒推导，不是独立检测框；头顶延用现有工程比例估算。历史三样本本轮只做人脸检测，并未完成换装自然度验证；OWNER缺可靠肩点、NET-02超肩角门槛仍不可放行。

默认安装包含JAX/绘图库等额外依赖，已停止本轮全量下载并保留日志/容器；实际验证将官方wheel中的核心任务模块在隔离目录加载，绕过顶层绘图依赖导入。此加载方式只用于本地候选验证，不能当成已验证生产部署方式。没有修改生产依赖/锁文件。

代码变更仅实验脚本，无业务源码变更；模型运行断言及25回放通过，未重复执行前端测试、类型、Lint或构建，不重复报告旧通过结果。照片上传0，百度调用0，未升级套餐或发布小程序。

后续必须完成生产可维护的人脸接入方式、授权边界和完整链回归，以及历史/跨样本自然度验证。不能因自动脸点候选成功而解除所有质量验收项。
