# 一次性几何对照

官方MODNet ONNX示例在commit28165a451e4610c9d77cfdf925a94610bb2810fb按长宽比例计算短边512、向下取32倍数；本项目preprocess却拉伸成512×512。稳定ONNX输入/输出为动态height/width。本轮仅验证几何输入假设：沿用现有双线性RGBA缩放、同归一化和同权重，将输入/输出改为官方尺寸规则的矩形；并非官方INTER_AREA完整复现。官方插值差异未同时改，避免多个变量混淆。只对同一5图各做一次，无阈值变化、不代替原失败基线。结果仍不达标即停止本路线，不继续尺寸搜索/阈值试错，不启用生产。

来源：https://raw.githubusercontent.com/ZHKKKe/MODNet/28165a451e4610c9d77cfdf925a94610bb2810fb/onnx/inference_onnx.py 。该源码明确INTER_AREA；本轮双线性只为隔离几何，不冒称与官方完全等价。
