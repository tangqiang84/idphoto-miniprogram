# RC-10 先调整照片尺寸再换装

用户决策：先调整相片大小，按相片大小换装。影响T1/T3。
基线：工作画布允许220万像素，云人脸/服装接口最多160万；实际三云调用仅验证576×768，不覆盖600dpi工作图。统一缩放本身不会改变颈肩比例，不能宣称解决自然度。
计划修改：新增纯逻辑suitImageSpace，poseService生成同一张等比768长边识别图；cloudFaceService将点映射到工作图后度量；cloudClothingService将掩码映射到工作图；t1Processing接线。仅缩识别图，保留原工作像素及用户确认裁剪。
验收：大图识别输入受限；人脸/双肩/衣物回到同一坐标；无放大、无拉伸、无隐式重裁剪；撤回授权零新请求；T1/T3关联测试、核心/类型/Lint/隔离构建。
不涉及：新增云真人调用、改模型/阈值、升级套餐或正式发布。视觉缺陷另列，不以尺寸回归代替。
