# RC-09图片云请求载荷离线核查

2026-11-10。生产未改，不调用云。envelopes.json用全零合成像素生成与当前core同字段JSON，audit.js独立复读5组字段/长度通过，不含人像。

成功模拟器上传312×470与290×438对应请求782217/677577字节；591×827为2606841字节；当前像素保护640000附近约3413473–3414389字节，因宽高舍入实际可略超640000。alpha回包基准约0.17–0.85MB；JSON服务字段额外开销另计。旧手机没有请求尺寸，不能认定其确为3.4MB或已超平台限制。

源码注释声称5MB限制，但本轮尚未取得适用于当前微信手机SDK版本的直接官方大小证据；不得据注释作规范。公开CloudBase资料有同步请求响应6MB等平台描述，也不能替代微信客户端通道的具体边界。不引用其他厂商/第三方博客证明微信上限。

结论：请求量级差异是待证伪假设，非修复结果。最小后续实验为同手机发送一个与当前大载荷量级一致的纯合成字符串（无图），使用capabilities入口拒绝额外测试字段，不解码图片/调用百度；若得到明确服务器拒绝说明大请求可达，若SDK拒绝则安全码进一步定位。此为新的CloudBase请求，原一次无图授权已耗尽，须单独确认；未执行，不以连续缩小尺寸调参求过。

本轮无业务代码变更，不重复单测/Lint/类型/构建；只运行本机载荷尺寸核验。现有功能/质量/手机云失败状态保持。
