# Android相机卡死阶段实验

最新有效事实：Redmi9/微信8.0.77，拍照后未进入裁剪页，微信整体无响应。此前“已到裁剪/只有框不动”由用户明确更正，撤销为依据，历史保留。

根因未确认，代码只证明setCameraOpen(false)之后立即开始getImageInfo，没有等待渲染提交；这不是原生相机资源冲突的实证。原15秒补丁只处理JS可运行时的Promise挂起，无法解开原生/主线程冻结。

实验：新增隔离快照，保留产品取图/相机参数，仅在高风险阶段前后写入单个本地阶段码；新增首屏显示最后阶段，支持一键进入产品首页。不存照片、路径、base64、身份；不上传或开启云能力，云/姿态适配器明确阻断。记录写入会影响时序，因此即使此包不复现也不能当修复通过。结果用于决定下一次最小对照，不盲目降分辨率/换相机API。

计划修改仅新快照hook/CameraGuide/首屏/app.config及云阻断适配器；生产不改。执行类型/Lint/构建，核查打包无测试图/模型。预览准备后需用户选择是否再现，单次拍照；若复现重开读阶段码，不反复扫码。未拿到手机阶段前不写根因或修复完成。
