# RC-10 标准人脸运行包

目标：以标准mediapipe公开API导入完成CPU人脸检测，不依赖旧最小加载实验的模块注入。固定mediapipe0.10.32，原FaceLandmarker模型SHA不变。官方wheel根模块实际导入drawing_utils，需cv2/matplotlib；采用无GUI的opencv-python-headless（只提供同一cv2接口），并验证标准导入与运行。所有新增依赖仅在独立目录，未修改生产锁文件；未来包体、许可、云ABI与部署前均须核对。

计划文件：本目录运行包/检测脚本，验证通过后才新增独立云人脸函数和T1/T3授权内后备接口。验收单人/无人/多人、固定来源、结构化错误、撤回与迟到拒绝、现有端侧路径保持优先。不修改其他工具，不上传新真人照片，不升级套餐。跨样本视觉与真实页面链仍必须独立验收。
