# RC-09 配置检查入口拒绝根因

## 可证伪实验

基线：首次只读请求仅包含action，线上返回CAPABILITIES_PAYLOAD_INVALID；源码回读SHA已确认部署一致，排除部署旧代码。假设为平台附加字段；临时诊断只返回受限字段名/类型，不读取字段值。实际线上diagnostic-response.json观察到唯一额外字段tcbContext，类型object；图片处理false、外部模型调用0。实验结束恢复原线上文件。

根因：入口把业务data与平台附加上下文混用同一字段白名单，仅认可userInfo，错误拒绝真实CloudBase附加的tcbContext。官方用户信息文档确认身份注入，但未列完整事件字段；具体tcbContext来自本次真实运行证据，不扩大为所有平台版本保证。

修复：只将已观察到的tcbContext作为忽略字段，不读取其值，不用于授权/选择provider。未知字段和原图/像素/provider等业务参数仍拒绝；原照片链不改。新增测试：平台值getter抛错依然只读检查成功；配置依赖显式env，嵌套上下文无法覆盖；同时带业务字段仍拒绝。临时诊断响应在最终代码中移除。

边界：本次配置检查成功不等于模型请求成功、不证明部署地域、保存/训练条款或成品质量。继续保留11照片中的两个质量FAIL、Android及其他未验项。

文档：https://developers.weixin.qq.com/miniprogram/dev/wxcloud/guide/functions/userinfo.html；已保存userinfo.html。parameters.html返回HTTP错误，未用其作依据。
