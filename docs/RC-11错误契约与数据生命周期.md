# RC-11 错误契约与数据生命周期

T1/T2/T3/T5 共用处理会话，T4 使用动作授权与检测代次，T6 使用拼版代次。平台回调超时、用户撤回或离开后，旧结果不能恢复预览、成品或自检。

| 层 | 错误与诊断 |
| --- | --- |
| 共享会话 | 对外错误包含 `code`、固定中文 `message`、`retryable` 和 `traceId`。任务尚未开始时可能没有 TraceID。超时和处理失败可重试；授权不足需先补授权。页面展示可用的 TraceID。 |
| 云调用 | 保留数字 SDK 错误码供降级判断，消息用固定文案。诊断关联本次调用 ID、合法的上游任务 ID 和已返回的云函数 ID。没有响应时，仍有任务和调用 ID，云函数 ID 可能为空。日志不打印 SDK 原文、图片或凭据。 |
| T4/T6 | 文件读取、图像加载、检测或编码回调使用有限等待。T4/T6 捕获失败后显示固定文案、原因码与 TraceID，释放忙状态。T6 旧图片加载回调在下一步导出前再次检查代次。 |
| 清理 | `localPurge` 只接收调用方指定、通过校验的临时图片路径。去重并拒绝持久目录、路径跳转、编码或带参数的路径。单文件失败返回固定原因码，微信 unlink 回调最多等待 3 秒，继续处理其余文件。 |

| 事件 | 资源处理 |
| --- | --- |
| 超时 | 停止等待并释放忙状态，作废输出和自检。已经发出的 SDK 请求可能仍结束，迟到结果丢弃。 |
| 取消 | 停止共享会话并调用已登记的取消回调，清理派生缓存，保留当前照片和参数供用户修改或重试。 |
| 撤回授权 | 递增版本、使在途操作失效、释放派生缓存，阻止旧任务继续上传。T4 清除检测结果；重新授权后可重新发起。已发送的请求不能撤回。 |
| 离页 | 释放订阅、会话源图/裁剪/授权引用、共享处理缓存和预览引用；T4/T6 迟到结果不得提交。 |
| 临时文件 | 会话释放指内存引用失效。物理删除须由人工授权后显式调用清理适配器，本轮仅用隔离替身验证。云端存储销毁和真机文件残留须另行验收。 |
