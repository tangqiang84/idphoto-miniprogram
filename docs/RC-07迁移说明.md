# RC-07 多工具流程迁移

2026-11-04。当前实现及证据见[验收报告](验证记录/RC-07-implementation/验收报告.md)。早期开发记录和失败报告继续保留，不能用它们代表迁移后的当前状态。

## 工具差异

| 工具 | 流程 | 约束 |
| --- | --- | --- |
| T1 | 裁剪→美颜→抠图换底→可选换装→预审→档位→成品 | 原规则保留 |
| T2 | 裁剪→美颜→抠图换底→预审→档位→成品 | 规格必选，无保持原图或换装分支 |
| T3 | 裁剪→美颜→抠图换底→必选换装/自检→预审→档位→成品/再自检 | 九规格；未实际换装或未自检不能导出，无跳过入口 |
| T5 | 裁剪→档位/KB→成品 | 纯图像裁剪缩放压缩，不调用检测/抠图/美颜/姿态 |
| T4 | 原图只读检测 | 不生成、不改写原图 |
| T6 | 独立拼版 | 不依赖人脸授权或其他工具先执行 |

T2/T3/T5为薄路由，复用`components/PhotoTool`、`useT1Workflow(tool)`、`createT1Workflow(...,{tool})`及`createT1Processing(tool)`。函数历史名称保留以兼容T1；没有复制新的完整图像管线到三个页面。T1现有页面继续复用同一会话/处理层。

## 会话及输出

`processingSession({tool})`集中保存原图、规格、裁剪窗、美颜、底色、换装、档位、授权；T5增加customTarget/kbLimit。T2接受标准底色、合法HEX/RGB、渐变描述和null透明；T1/T3底色范围不扩展，非T5自定义像素拒绝。

输入变化使相关结果/预审/自检失效；旧任务、旧保存/修补回调不得消费新结果。裁剪窗使用原图坐标，后续换底、换装及档位仍传同一确认窗。T3只改档位后返回预审可继续，最终新成品仍重新自检。RC-06的实时授权、撤回和取图/质量提示版本保护保留。

选图仅进入裁剪；确认裁剪后T1/T2/T3进入美颜，确认/跳过后才抠图。T5确认裁剪后直接档位，平台分支直接读取已选范围并缩放，不经过prepareWorkCanvas的人脸度量。

T5自定义宽高为1–5000整数，越界拒绝，不静默截断；自定义尺寸不随dpi翻倍。标准规格仍按300/600档输出。显式KB上限在有限质量序列中压缩；无法满足则不提供成品保存，0表示关闭自定义压缩上限。该上限由用户明确选择，不与其他工具600档的机构KB提示例外混用。

## T2颜色与素材例外

颜色控件使用core/color解析HEX/RGB，越界不调用处理。渐变两端与角度独立设置，0°向右、90°向下；CSS预览角度为90°+产品角度。反向渐变投影包含负轴起点偏移。

T2先按裁剪窗得到透明前景，再以最终照片坐标合成底色，避免工作画布余量截去渐变端点。预览和最终成品使用同一背景描述；切换纯色不会残留渐变。透明输出保留PNG Alpha；部分透明不等于抠图视觉质量已合格。

用户已确认透明PNG可作图像素材。T2不符合规格的底色显示风险，不宣称证件合规；尺寸、文件大小等其余检查保留。300档PNG大小超限仍阻断，600档按既有机构KB提示例外执行。T1/T3的预审/底色规则不因此放宽。
