2026-11-06。当前本机关键链路已有通过证据，抠图质量研究停止，不再循环追加相同本机测试。整体仍未完成。

| 缺项 | 需要的输入 | 拿到后执行 |
|---|---|---|
| 实际CloudBase地域 | 当前环境控制台非敏感地域信息；可用环境名/ID尾部区分，勿含凭据 | 与目标环境核对，归档证据；不是以平台支持地域推断 |
| 百度具体服务承诺 | 人像分割订单/具体服务规则中的留存、销毁及训练用途约定名称/公开条款 | 核对适用产品和版本；不存在即保留承诺未证实，不擅自推断 |
| iOS/Android产品验收 | 手机可接入及系统网络切换配合 | 本地处理→质量不足云路径、拒绝/撤回、断网恢复、最终保存；研究模型不在范围 |
| 完整产品云处理 | 明确素材及百度目标/费用授权 | 最小固定批次，不沿用已用完的三次授权；先提供具体计划 |
| 真实受控故障与性能 | 可用设备及安全故障方案 | 不耗尽真实配额，替身不当真实故障；冷/热端到端分开记录 |

## 当前覆盖决定（2026-11-06）

用户明确百度服务约定与CloudBase实际地域不再考虑，以上两项历史缺口从当前RC-09必需范围移除，不当“已验证”。目前仅保留手机、完整云链及故障/性能；具体可执行方案见[集中验收](验证记录/RC-09-device-ready-20261106-01/集中验收方案.md)。当前构建114输入/43产物校验一致，待手机配合和具体云调用授权，不再索取账户条款/地域信息。
