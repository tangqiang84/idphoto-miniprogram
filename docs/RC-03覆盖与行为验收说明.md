# RC-03 覆盖与行为验收说明

日期：2026-10-28。需求依据：RC-01-v1.2、PRD与原型的已确认决策。依赖RC-01、RC-02已完成。

## 范围与复现

原矩阵只登记50项，按脚本存在性认领整条需求；组件数量/标签顺序被当作独立步骤通过，像素脚本被映射到隐私承诺。原实现与旧矩阵均留存，见本轮报告。

本轮修改需求登记、用例协议、矩阵生成器、步骤探针、断言测试及Lint文件范围。未修改业务源码、生产依赖或锁文件。修复产品流程归RC-04/05/07，授权归RC-06，质量与部署证据按各任务补齐。

## 交付与口径

- `prd_requirements.json`覆盖基线全部76项，保持需求描述，登记来源、工具、主协议/部分断言及后续任务。
- `coverage_cases.json`包含76个主验收协议与10个可执行部分用例。每条包含input/action/expected/negative/environment/limitations/evidence_policy。主协议不是已实现测试；主协议与局部单测分开登记。
- 6个局部单测覆盖上传边界、RGB/HEX与渐变采样、9规格双档固定期望、禁止变形美颜、排版与合规引擎。不能推导页面接入或真实成品合格。
- 4个页面控制流探针执行T1/T2/T3/T5当前TSX控制代码与真实授权hook。用替身交付合法PickedImage并记录确认裁剪前的下游调用，不只查组件；源码哈希与环境写入报告。
- Node探针不运行真实React/Taro渲染、触控、相机、模型、网络；不读取/上传照片。适配失败或无合法输入观测为BLOCKED。只证明观测区间内的行为，后续完整交互仍须微信端实测。
- 境内处理/不留存/不训练等由external协议要求部署配置、请求链路、服务条款与审计证据，像素检查不能代替；模型商业许可也须独立证据。
- 估算与mock不计实测肩线达标率；预期拒绝与正常照片处理分别分类。故意违规输入必须让断言FAIL，环境缺失必须BLOCKED。

## 命令与退出码

```bash
node 工具链/coverage_matrix.js --validate
node 工具链/coverage_matrix.js --json
node 工具链/coverage_matrix.js --check
node --test 工具链/tests/*.test.js
node 工具链/smoke_steps.js --node
node 工具链/smoke_steps.js --node --tool T1
bash 工具链/verify.sh
bash 工具链/verify_all.sh --no-ide
```

矩阵：`--validate`退出0只代表登记校验；`--check`缺少完整验收证据退出1，由RC-02里程碑入口解释为BLOCKED；非法登记/参数退出2。检查包括非空清单、与RC-01全部需求编号/描述一致、双向引用、唯一编号、必填字段、真实文件及断言定位、证据类别。`--req`自定义清单也须完整匹配当前基线，不能缩减需求来放行。文件/定位存在仍不证明断言语义充分，须代码审查与负例测试。

矩阵不会从脚本存在或单测通过自动推导需求通过；当前执行状态统一NOT_RUN，76项均待补主断言或人工/部署证据。主断言实现后仍须增加匹配代码与环境的完整执行证据，不能仅改登记来消除缺口。当前生成器不导入历史PASS。

矩阵默认写入唯一新报告目录；`--out 新文件`拒绝覆盖；`--print`只打印，`--json`只输出JSON。`docs/覆盖矩阵.md`是本轮索引快照，旧版已归档。

步骤探针：退出0=本次观测区间通过，1=提前调用，2=参数/输出错误，3=无法观测。产物默认进入唯一step-flow目录，`--out 新目录`拒绝覆盖。旧IDE版本为`smoke_steps_structure_legacy.js`，仅保留历史结构检查用途；旧矩阵生成器为`coverage_matrix_legacy.js`，禁止按旧固定输出方式重跑。

开发入口仍只执行core单测、类型、Lint、构建。RC-03断言测试和页面探针须另行执行；里程碑保留覆盖缺口阻断，不会被开发检查PASS放行。
